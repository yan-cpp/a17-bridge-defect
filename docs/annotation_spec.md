# A17 数据标注规范

本规范用于统一 GYU-DET、dacl10k、CrackSeg9k 和自采数据的标签口径。所有进入训练的数据必须先转换为 A17 内部类别。

## 1. 内部类别

| ID | Key | 中文名称 | 阶段 |
|---|---|---|---|
| 0 | crack | 混凝土裂缝 | 1 |
| 1 | spalling | 剥落或掉块 | 1 |
| 2 | exposed_rebar | 钢筋裸露 | 1 |
| 3 | rust | 钢结构锈蚀或混凝土锈染 | 2 |
| 4 | efflorescence | 泛碱或渗水 | 2 |
| 5 | honeycomb | 蜂窝面或孔洞 | 2 |

## 2. 源类别映射

GYU-DET 的 `classes.txt` 类别统一映射如下：

| GYU-DET 原始标签 | A17 内部类别 |
|---|---|
| Crack | crack |
| Breakage | spalling |
| Reinforcement | exposed_rebar |
| Seepage | efflorescence |
| Comb | honeycomb |
| Hole | honeycomb |

dacl10k 映射关系见 `configs/data_mapping.json`。

## 3. 图像规范

- 支持 jpg、jpeg、png、bmp、tif、tiff。
- 保留原始分辨率，不做有损压缩。
- 最短边不得小于 64 像素。
- 文件名必须唯一，建议使用 `source_imageid` 形式。

## 4. 检测框标注

- 使用 YOLO 归一化 `class x_center y_center width height`。
- 类别索引从 0 开始。
- 所有坐标必须是 0 到 1 之间的浮点数。
- 边框标注完整可见目标；边缘截断目标不标注。
- 遮挡但仍可识别的目标保留标注。

## 5. 实例分割标注

- 优先使用多边形格式，其次使用像素Mask。
- 每个病害实例单独一个多边形或一个Mask。
- 只有语义分割标签时，可将同一类别的不同连通域拆为实例，但必须记录拆分规则。
- Mask面积小于4像素的实例可以丢弃。

## 6. 困难样本与干扰项

以下对象不得标注为病害：

- 施工缝
- 阴影
- 水面反光
- 涂鸦
- 爬墙虎和植物
- 模板痕迹
- 密封胶

困难负样本需要保留在训练和测试集中。

## 7. 数据划分

- 按桥梁编号、拍摄批次或拍摄日期划分。
- 同一桥梁的相邻帧不得跨训练、验证和测试。
- 默认比例：训练 80%，验证 10%，测试 10%。
- 固定随机种子 42。

## 8. 数据质检

每条数据必须通过以下检查：

- 标签文件不能为空。
- 图片文件名和标签文件名对应。
- 类别索引在合法范围内。
- 检测框坐标在 0 到 1 范围内。
- Mask 尺寸与图像尺寸一致。
- 训练、验证、测试之间没有重复文件名和同源泄漏。
