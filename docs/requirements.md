# A17 Requirements And Scope

## Objective

实现一套可运行的桥梁表观病害检测系统。系统接收无人机采集的桥梁图像或视频，输出多类别病害检测结果、实例分割掩膜以及可追溯的物理尺寸量化结果。

## Phase 1 Scope

第一阶段仅实现以下三类：

| Key | 中文名称 | 说明 |
|---|---|---|
| crack | 混凝土裂缝 | 包含细长裂缝、交叉裂缝和表面裂缝 |
| spalling | 剥落或掉块 | 包含混凝土剥落和局部掉块 |
| exposed_rebar | 钢筋裸露 | 包含露筋和钢筋外露区域 |

`rust`、`efflorescence`、`honeycomb` 保留到第二阶段。

## Input

- 单张 JPG、JPEG、PNG 或 TIFF 图像。
- 图片目录和批量清单。
- 视频文件或后续扩展的视频流。
- 可选的相机标定信息：飞行高度、焦距、传感器尺寸、云台角度、毫米每像素系数。

## Output

每个输入必须提供：

- 图像标识和处理时间。
- 病害类别和置信度。
- 目标检测框。
- 实例分割Mask。
- 物理长度和最大宽度。
- 像素到物理尺寸的转换系数。
- 模型版本、配置版本和推理耗时。

详细字段见 `docs/output_schema.md`。

## Acceptance Criteria

- 至少支持3类病害。
- 检测、分割和量化模块构成完整闭环。
- RTX4090级别GPU上4K图像端到端P95不超过200ms。
- 检测和分割指标不低于选定基线。
- 提供图片、批量和视频输入Demo。
- 每个核心指标可以复现，实验参数和模型版本可追溯。
- 训练、验证和测试数据按桥梁、拍摄批次或日期隔离。

## Non Goals In Phase 1

- 不实现无人机飞行控制。
- 不实现桥梁三维重建。
- 不把物理尺寸精度建立在未标定的假设之上。
- 不在第一阶段扩展到六类病害。
- 不把分类数据集直接当作实例分割数据使用。

## Deliverables

- 可复现的代码仓库。
- 训练、验证和测试数据清单。
- 模型权重和推理脚本。
- 量化模块和标定参数。
- Demo系统和使用说明。
- 技术方案、实验报告、PPT和演示视频。
